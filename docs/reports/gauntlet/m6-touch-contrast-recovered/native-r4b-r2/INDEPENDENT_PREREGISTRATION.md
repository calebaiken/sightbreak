## Fixed interpretation and unresolved gates

The controller has no whole-operation deadline. Its analyzer has no explicit
timeout, and cleanup's final wait() is unbounded. Archival compression also has
no explicit timeout. These are retained method limits, not newly bounded work.
Cleanup code signals groups only while the recorded leader is running; the
actual audit therefore checks group members separately. The source acceptance
does not certify those runtime facts before they occur.

The registered final-contour gate uses a qualified native contribution and a
connected witness within four pixels. It cannot identify the true underlay
from opaque P/B/W alone; an inward contrasting band can pass while the outer
contour is invisible, and component minimum alpha cannot prove every internal
primitive survives. Preserve these previously demonstrated falsifiers and any
native manifestations. Keep hidden intermediate strokes in the diagnostic
report. The 32-scene source geometry certificate is historical source support,
not new native or physical evidence.

outside its packet. This reviewer knows source identities and cannot fill that
