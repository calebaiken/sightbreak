## Required next model boundary

Carry a persistent feasible rejection/deadline hypothesis per identity across
all observed prefix projections. An observed noninitial deadline pins a rejected
state and its sole reject time. That state freezes last_input and preserves its
deadline forever until forget/new generation. An initial-deadline observation
allows an unrejected state and, when timing permits, a coincident rejected state;
a later changed deadline must be compatible with that same earlier observation.
Use inclusive same-millisecond order alternatives rather than one guessed order.

The current connection/last_input/binding fix is retained as improvement; adding
four or32 isolated example guards does not establish this persistent relation.

ordering, coalesced accepted ownership, later invalid precedence and hypotheses
that remain genuinely unresolved. I did not claim exhaustive coverage of those
other registered families from the deadline result. Conservative UNKNOWN limits
and the still inconsistent legacy connected helper remain explicit obligations.
