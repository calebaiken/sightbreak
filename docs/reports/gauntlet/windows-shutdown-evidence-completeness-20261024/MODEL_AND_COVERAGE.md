# Evidence model and reviewable coverage

This is a required-producer-envelope checker. It inventories every observed file,
validates the successful source's required formats and relationships, and uses
trusted collection identity/owned-process observations. It does not certify pixels,
Tesseract accuracy, gameplay validity, native API behavior, an atomic all-files
snapshot, or independent quality. independent_qualification remains UNREVIEWED.
The builder cannot close that gate. Public collection remains retention BLOCKED.

## Executable families

New envelope tests generate a producer-shaped53-file ordinary/verbose fixture and
preserve all unknown originals. They cover every53 single-file omission, valid-
context missing results/passed-only, duplicate/nonfinite/empty/wrongtype/invalidUTF8
JSON, PNG CRC/raster/filter/truncation/dimension errors, empty OCR and all receipt

missing/mismatched births/exits/callback copies/close errors/budgets, native error/
leak/ANGLE warnings, typed order/deadline/driver errors, and injected model veto.
Positive controls retain distinct signed seeds, requested/captured dimension
differences, complete unknown extras, Windows CRLF stdout, after-cleanup elapsed
beyond300, and a wall-clock step without inventing a deadline extension.

Wrapper tests call only real_driver with a fake imported main enforcing the actual
empty-dir condition. Success, invocation failure, capture collision, publication
collision, partial-copy failure and publication-receipt error all retain original
streams/causes and fail safely where appropriate. No actual living driver or
native helper runs.

The executable fixture is declared synthetic format data: solid PNGs, mocked OCR,
engine clocks and gameplay subreceipts cannot establish physical input, timing or
visual outcomes. Root will assign another existing independent critic to inspect
these actual files/controls and fresh falsifiers after freeze. The builder's
passing test assertions are validation evidence, not that critic's verdict.
