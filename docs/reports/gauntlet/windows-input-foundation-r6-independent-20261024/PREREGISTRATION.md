## Necessary interval contract

The following are necessities for a source-proved continuously live, bound identity `(peer,generation)` within one authority epoch/stream lifetime. A mere reused peer number, latest packet projection, guessed callback success, or unresolved nested disconnect is not enough to establish that domain. Use observed connection/binding/retirement facts and preserve UNKNOWN when the domain itself is unsupported.

Let q0/q1 and a0/a1 be the selected stream's observed queue cardinalities and ACKs at two such cuts; let A,C,K be the nonnegative GLOBAL deltas of accepted calls, consumed calls and skipped commands over their interval. These globals bound local changes even when ownership is unknown; they do not prove local ownership.

| Necessary fact | Source basis and boundary controls |
| --- | --- |
| ACK domain is-1 or a positive integer | No source writes ACK0. Test absent/popped values and schema-valid0. |
| ACK cannot decrease/clear in this live same-epoch domain | Popping writes a newer sequence; only forget/reset clears it. Test positive regressions and positive→-1, even after earlier UNKNOWN. |
| C=0 implies unchanged selected ACK | No pop anywhere means no local ACK writer. A>0, pending RX, J/gate/decode counters do not write ACK. |
| A selected ACK increase requires a possible local pop | Other peers' global pops cannot force this peer's ACK to increase. Proved local pops impose an increase; ambiguous C>0 does not. |
| A newly counted latest consumed call owned by this same identity must equal its current ACK | With C progress since this identity's earlier cut and no epoch/lifetime break, the latest global pop is after that cut. If its peer/generation is this identity, any still later local pop would itself replace that latest projection. Acceptance cannot rewrite ACK. Do not apply equality to another owner's latest pop or stale metadata across a reset. |
| max(0,q0-C-K) <= q1 <= min(120,q0+12A) | Each local pop/skipped key removes one entry; only accepted calls can add at most12. Global deltas are conservative local bounds. In particular A=C=K=0 forces q1=q0 regardless earlier receipt owner. |
