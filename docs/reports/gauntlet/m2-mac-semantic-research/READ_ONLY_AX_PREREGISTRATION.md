## Public read-only AX contract

Use public ApplicationServices APIs (`AXUIElementCreateApplication(exact_pid)`, `AXUIElementGetPid`, read-only attribute/count/bounded-value functions). Resolve only that application's windows; retain each returned window's PID/role/position/size and require one candidate matching the sole current owned visible CG/ScreenCaptureKit window. Traverse only that owned window's accessibility children, with a maximum depth of **16**, maximum **256** examined nodes, maximum **512 KiB** serialized receipt and a **0.25s per-call messaging timeout**, all within the fixed 5s AX budget. Use bounded child-count/value reads; oversize counts, cycles, truncation, unsupported/malformed attributes and timeout leave a failed/incomplete observation. A process supervisor enforces elapsed bounds and retains helper stdout/stderr/status. Never increase a timeout or retry after a hard failure.
