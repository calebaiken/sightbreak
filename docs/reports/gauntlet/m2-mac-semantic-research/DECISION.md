Status: **supported source route; exported AX tree unobserved**. This report proposes a read-only diagnostic. It does not approve source, dispatch a run, replace the OCR selector or qualify gameplay.

## Inspected benchmark and decision criteria

The actual benchmark is [run 39920948579](https://github.com/calebaiken/sightbreak/actions/runs/39920948579), job `120305758766`, independently retained at `460fe42`. Its [original review](https://github.com/calebaiken/sightbreak/blob/460fe42/docs/reports/gauntlet/m2-mac-derived-ocr/native-c838-independent/NATIVE_REVIEW.md) and artifact hashes remain authoritative. The raw 1004×664 and fixed 2× 2008×1328 images each report one `DEPLOY • OFFLINE 5V5` caption at confidence **0.5**. The unchanged **0.8** gate rejects before any CGEvent. Reading these original pixels confirms a visible Deploy button, without supplying higher OCR confidence. Ordinary gameplay remains unqualified. Earlier native failures and source rejections remain retained in their original branches; none is relabeled here.

Research criteria supplied before this investigation were: prove a mechanism in the pinned engine source; preserve normal product behavior, privacy, authority and all existing gates; prefer PID/window/button semantics; reject blind navigation and arbitrary coordinates; distinguish source support from actual exported observations. This document records completed research, not a retrospective native preregistration. [READ_ONLY_AX_PREREGISTRATION.md](READ_ONLY_AX_PREREGISTRATION.md) declares the proposed next component before helper, tests or workflow implementation.

## Current product and keyboard behavior

[main.gd:209](https://github.com/calebaiken/sightbreak/blob/c838907cf4978e53c57423e08c23277c34f4496d/game/scripts/main.gd#L209) creates normal `Button` nodes and connects their pressed callbacks. [menu_entry:434](https://github.com/calebaiken/sightbreak/blob/c838907cf4978e53c57423e08c23277c34f4496d/game/scripts/main.gd#L434) preserves that type; [menu_columns:453](https://github.com/calebaiken/sightbreak/blob/c838907cf4978e53c57423e08c23277c34f4496d/game/scripts/main.gd#L453) creates Deploy first and connects its ordinary stock offline start. The exact visible label is `DEPLOY   ·   OFFLINE 5V5`. There is no menu accessibility override. `Menu_deploy` is a scene node name, not proof of an AX identifier.

Godot [BaseButton:640](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/scene/gui/base_button.cpp#L640) defaults to `FOCUS_ALL`, handles normal [ui_accept](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/scene/gui/base_button.cpp#L96), and defaults [Tab / Enter / Space](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/core/input/input_map.cpp#L453) are present. SIGHTBREAK does not intercept these keys in its `_input` method. However, it has a [Node scene root](https://github.com/calebaiken/sightbreak/blob/c838907cf4978e53c57423e08c23277c34f4496d/game/main.tscn) and creates its Control under a CanvasLayer; it does not initially call `grab_focus`. Godot's [no-current-focus fallback](https://github.com/godotengine/godot/blob/ed1daf0bf001b61586d9930840f2f1394092c079/scene/main/viewport.cpp#L2323) searches direct Viewport children for a Control. Consequently, source does not establish first-Tab focus or a safe Tab/Enter sequence for this layout. No blind keyboard alternative is proposed.

## Decision and remaining limitation

Proceed, after separate source review and root release, to a **single bounded read-only AX preflight** of the exact exported artifact, with the sole additional engine setting `--accessibility always`. First prove that the actual app exposes a unique owned-window Deploy button with semantic role, exact label and frame. Preserve original native PNG/Vision rows, including low confidence. Do not send input, perform an AX action, change the existing selector, or reinterpret AX data as OCR confidence.

The existing `.github/workflows/desktop-alpha.yml` is supported by the actual ARM run above. A later reviewed opt-in diagnostic mode on this existing workflow/ref can run only source controls, exact export and the read-only probe; its normal lanes and strict/full-journey gates must remain unchanged. The Intel-only render diagnostic changes diagnostic rendering inputs and is not the selected ARM path. No mode or workflow is implemented here, and another full gameplay retry is not requested.

The concrete external uncertainty is the actual exported AX tree and the future observer's AX trust/coordinate receipts. A dummy driver, empty/busy tree, denied query or ambiguous window/button must remain a retained diagnostic failure. If the tree is useful, a future separately preregistered semantic targeting method may be considered. Ordinary Deploy/fire/reload/leave and all release criteria remain blocked until their original or explicitly reviewed method is actually observed.
