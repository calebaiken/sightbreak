## Criteria fixed before inspection

1. **Exact scope and preservation.** Verify candidate commit ancestry and file
   boundaries. Shipping game/scripts/tests, original thresholds, raw receipts,
   source/ownership records, input, privacy, protocol 6, authority, opt-in
   prediction, live-rewind policy, and economy boundaries must stay unchanged.
   Compare exact relevant source bytes and retain observed setup failures.
2. **Truthful complete label coverage.** A declared mask must account for the
   complete rendered label, including anti-aliased pixels, bearing/advance,
   overhang, clipping, alignment, transforms, outline/shadow, fallback/shaping,
   font options, and draw order where applicable. A guessed rectangle, crop,
   nonempty mask, successful array shape, or glyph advance alone is insufficient.
   Unknown or unobserved coverage must fail closed.
3. **Unique ownership.** Each retained label pixel must have one correct control
   owner, remain within that control's component and actual hit geometry, and
   resist overlap, duplicate/foreign owner, dropped edge, shifted mask, empty
   glyph, and orphan controls. No recovery may silently reassign a pixel merely
   to satisfy a rectangle. Known JUMP overhang must be addressed explicitly.
4. **Quantization soundness.** Derive the claimed bounds independently. Check
   every feasible interval endpoint and threshold boundary with bounded pure
   controls, including spread 0/1/2, clipping/saturation, alpha endpoints,
   channel disagreement, wrong model, unsupported transfer/blending, and ratios
   around the unchanged 3:1 criterion. A necessary condition must not be reported
   as sufficient or as an observed contrast pass. Uncertainty must produce
   inconclusive/reject outcomes rather than false acceptance.
5. **Completeness and conservative error.** Test meaningful adversarial inputs
   in addition to builder controls. Check non-finite/malformed values, duplicate
   coordinates/owners, invalid dimensions, missing or unsupported metadata,
   unsupported alpha/colour models, and correlation assumptions as relevant.
   Report any valid pixels falsely rejected as a limitation without weakening
   the gate. State whether tests cover the claimed domain.
6. **Evidence and verdict discipline.** Retrieve actual pinned upstream API
   evidence independently if semantic claims depend on it. Distinguish design
   intent, pure prototype results, old rendered evidence, and new unobserved
   requirements. A method winner needs no false accepts in the tested domain
   and no unsupported completeness claim; unresolved blocking gaps reject it.
   State winner, why, single largest remaining gap, regressions, and evidence
   that cannot be judged. Blind visual ranking is unavailable for this method
   comparison and will not be fabricated.
