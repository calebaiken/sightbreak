# Integration process-boundary controls

These are retained **pure/synthetic tooling controls on pre-freeze source**,
not a native matrix, network, exported-game or device pass. The original failed
attempts remain unchanged outside the repository. `COLLECTION.json` binds every
copied byte to its external origin and lists generated bytecode omissions.

The controls show why a zero-exit root process is insufficient evidence:

- The critic's original matrix and export-watchdog entries could pass before an
  escaped descendant appended a late `ERROR`. Shared pre-launch containment now
  rejects that case, keeps actual root exit **0**, records `HARNESS_ERROR`, stops
  the descendant and persists failure.
- The original artifact verifier also passed an exited-root/late-child control;
  the corrected verifier rejects it. Its normal and optimized suites both ran
  **74 tests** with actual exit **0**; assertions removable by `-O` are not used
  as delivery gates.
- The campaign's **58-test** suite includes the same real CPython descendant
  control. Its retained passing child summary cannot override containment
  failure.
- Export-controller binary/receipt mutation and unbounded OCR were separately
  reproduced. Both flow boundaries now recheck exact bytes and receipts;
  bounded OCR retains partial output and a separate process watchdog limits the
  full flow. The completed **27-test** watchdog retry and the failed paging-file
  attempt both remain visible.
- The final serial batch runs eight non-native suites (**161 tests** total), all
  actual exit **0**, using isolated CPython **3.13.15**. It does not include the
  separately owned audio-negative-control or artifact-verifier suites.

Windows CPython containment was executed. Linux subreaper behavior, actual
Godot campaigns, extracted Linux ELF/wrappers and X11 game flows still require
the exact frozen-source CI run. Synthetic/mock exports must not be described
as built or played game artifacts. Initial failures are not erased by retries.

The campaign receipt predates removal of one unused test import; its recorded
source hash describes the executed bytes, not an assertion that every later
byte is identical. Each other receipt likewise retains its own source/time
scope. The collector is archival only: it does not rerun old controls.

`SHA256SUMS.txt` hashes every other published file in this subtree. Nested
attributes preserve copied evidence bytes, and the local ignore rule includes
raw logs. Generated Python bytecode is omitted and never force-added.
