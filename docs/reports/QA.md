# Independent QA report

Review date: 2026-10-12 (America/New_York). Scope: native Godot client, headless dedicated simulation, FastAPI/PostgreSQL economy and the original specification. The QA reviewer did not author gameplay or economy implementation and ran the checks below independently against the shared development checkout. Review included independent correction retests and a final full validation run. Evidence is scoped to the commands and observations recorded below; later changes require affected regression checks.

## Acceptance decision

**Development implementation; no full specification milestone accepted.** The requirement is at least **8.5/10 in every applicable category**, supported by evidence. There is no defensible conversion from a few automated assertions to a numerical mobile usability, visual polish, security or performance rating. Those criteria remain **UNVERIFIED**, not an assumed 8.5. Passing narrow checks below establishes only the described behavior. No physical mobile session, production security audit or 60 FPS benchmark was performed by this reviewer.

The runnable offline slice and separate economy transaction implementation are useful development deliverables. The requested journey from playing a real authenticated online match to earning tradable value was absent at first review. The scoped account-ticket admission path and trusted result bridge are now implemented and independently tested. A synthetic ten-account match payload traveled through the real Godot HTTP adapter into ten exact PostgreSQL wallets, with replay minting nothing. Guest LAN/bot/offline sessions remain ineligible. **A completed ten-human match earning account rewards has not been observed**; synthetic policy fixtures are not human play evidence.

## Actual visual and software-render observations

The reviewer inspected the native `menu.png`, `combat.png`, `refined-sidearm.png`, `refined-rifle.png` and final `combat-final.png` captures under `builds/qa/`. The final image shows readable HUD text on dark backdrops, recognizable original industrial geometry, corrected sign orientation, distinct team figures and a more detailed rifle. This supports visible improvement over the initial blockout, not a claimed production visual score or physical-device usability pass.

`builds/qa/render-metrics.json` records a **short Linux Xvfb / Mesa llvmpipe CPU software-render sample**, Godot 4.7.2, 1280×720: 30 sampled frames in 8.241628 seconds, mean 3.64006 FPS, mean 274.72093 ms/frame, p95 515.005 ms, 492 reported draw calls, 28,678 primitives and 79,282,563 bytes Godot static memory. The cloud run shared CPU resources with other work; this is an uncontrolled diagnostic sample. These numbers describe this cloud software-render run only. They are not a representative GPU test, sustained thermal test, device RSS measurement or mobile 60 FPS result.
